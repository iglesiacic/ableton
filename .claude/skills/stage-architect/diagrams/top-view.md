# Vista superior

Escenario arriba (fondo), público abajo. Esquema `ESTIMADO`, sin escala. Izquierda y derecha según la congregación.

```text
 FONDO ─ pared + pantalla
 ┌────────────────────────────────────────────────────────────┐
 │         [PAR01] [PAR02] [PAR03] [PAR04] [PAR05]   ← Barra B │
 │  (MH01)   (G1)    (G2)    (G3)    (G4)   (MH02)  ← piso    │
 │                                                            │
 │ [SPK01][SML01][BAR01] F1  F2  F3  F4 [BAR02][SML02][SPK02] │ ← Barra A
 │                                                            │
 │                 ┌─ tarima frontal ─┐                       │
 │                 └──────────────────┘                       │
 └────────────────────────────────────────────────────────────┘
   Público (sillas rojas, pasillo central)
```

Etiquetas: PAR01–05 = `TR2-PAR01..05`, G1–G4 = `FLOOR-PAR01..04`, MH = `FLOOR-MH01/02`, F1–F4 = `TR1-FRS01..04`, BAR = `TR1-BAR01/02`, SML = `TR1-SML01/02`, SPK = altavoces.

Falta la profundidad real (eje Y). Todo lo de arriba es orden, no distancia.
