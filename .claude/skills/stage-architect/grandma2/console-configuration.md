## Reglas de seguridad durante el levantamiento

- No modificar el showfile.
- No ejecutar `Delete`, `Store` sobre contenido existente, `Reset`, ni cambios de patch.
- Solo lectura: capturas de pantalla, exportaciones, o listas dictadas por el usuario.
- Si hace falta ejecutar un comando de lectura en la consola (por ejemplo `List`), pedir confirmación antes.
